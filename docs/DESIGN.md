# Delta — 设计说明（一页）

## 三份互斥方案

1. **无限画布树**（QGraphicsView）。节点按树布局，拖拽、缩放、空间化分叉最直观。代价：读一段长链要在二维里移动，焦点、滚动、重启恢复都变复杂；它把「读」降级成「逛」。否决。
2. **三栏常规聊天**（侧栏 + 气泡 + 树状目录）。实现快、认知门槛低。代价：树只是右侧附录，分叉在正文里不可见；三栏挤压阅读宽度；整体像一个换皮聊天工具。实际做了 V1 后否决。
3. **单脊线 + 层入口 + ATLAS（采用）**。正文只画根 → 视图叶的一条链；每一层用一行标签作为入口；右侧 ATLAS 给出整棵树的形状。代价：ATLAS 在几百节点会变密，标签只能截一行；换来连续的阅读和可解释的局部重排。

## 这一轮：把「指针」换掉

**状态三样**：

1. **结构**：节点 + parent；孩子的出生序只增不改；另有一个每层的展示序，只决定排列。
2. **默认**：字段挂在 parent 上，语义是「这一层的活动孩子」；至多一个，可空。
3. **基准**：一个节点；空对话为 None。

**派生四样**：

- **捷径链** = 根 → 基准（结构事实）。
- **锁层** = 捷径链经过的每一条边对应的层。基准 = 根时没有边，也就没有锁。
- **视图叶** = 从基准沿默认走到底。
- **视图** = 根 → 视图叶的祖先链。基准以上走结构，基准以下走默认。

**锁**：某一层在捷径链上，它的一切改动（切换 / 新建 / 关闭 / 重排）都不可用。解锁不是另一套操作，而是把基准抬到这一层的 parent；这一层离开捷径链，四类操作同时回来。视图按默认重新下落，允许跳。

**四个门**：activate / create / close / reorder，全部先 require_open(layer)。UI 只发意图。发送是 create 的组合，仍然过门；视图叶恒在基准以下，所以发送永远不撞锁。唯一的全局例外是「把捷径写进默认」：需要显式确认，只写链上各层的默认，不解锁、不改基准。

**写者清单**：

- 改层的活动孩子：切换 / 新建 / 发送 / 关闭（活动孩子被删时，展示序里的下一支接替，没有就前一支，再没有就留空）/ 固化（例外）。
- 改结构：新建 / 关闭 / 流式清理空占位（abandon）。
- 改展示序：拖拽。
- 改基准：set_baseline —— ATLAS、解锁确认、回到默认、防御性删除都调它；UI 侧没有第二个基准写入，也没有独立的 unlock 方法。

## 为什么是「层」

「选一支 / 加一支 / 删一支」听起来像三个按钮，其实是同一对象上的三类动作。把层作为最小单位，锁就只需要问一个问题：**这个操作改哪一层？那层在不在捷径链上？** 入口是标签、菜单还是快捷键，不影响判定。这样也不会出现「按钮绕过了锁」的漏洞。

## 标签条

标签条是层的入口，不是层本身。活动 = 视图经过的那支；标题取该支第一行；编号是出生序（删除后允许断号）。溢出用单行横向滚动 + 计数，不换行——上一轮的两行换行是高度抖动的来源。拖拽只改展示序。

单孩子层仍然有层，但这一轮不新开一行：它的入口是卡片右键菜单（新建 / 关闭 / 抬基准）。连体标签形态留到下一轮；不把旧按钮加回卡片。

## 砍掉

- 指针（当前位置）、首选圆点、从任意消息分叉的按钮、卡片上的删除/重试按钮。
- 路径副本；「重排就是清空重建」；标签条换行。
- Alt+←/→ 和 Alt+↑/↓：没有指针可走，兄弟切换只发生在看得见的层上。

## 迁移（schema 1 → 2）

旧可见链（根 → 旧指针）一次性写进默认，基准 = 根；如果旧指针停在分支中间，清掉它自己的默认，让首屏停在用户上次看到的那一节点。这样升级后首屏不变、无锁、回到默认不跳。链外节点的旧首选保留。不降级。

## 热路径

- **切换**：只改一个默认；视图前缀控件对象不动，只换后缀；回访复用缓存卡片。
- **流式**：只改一个卡片；14ms 批量。
- **重启**：原子 JSON +（行 key, offset）滚动锚点 + 基准。
- **门禁**：锁在调用时现算，不缓存，不存。

## 代价（不藏）

- 标签条切换会重建这一层的 chips（很小），但 25ms 级的切换仍然可能超过一帧；BENCH 里如实记录。
- 单孩子层这一轮没有连体标签，入口在右键菜单里，发现性差；下一轮补。
- ATLAS 没有搜索/缩放；几百节点会变密。
