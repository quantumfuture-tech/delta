# Delta

**一条链，一个基准。**

一个人对着模型工作。没有联系人、没有消息投递、没有已读回执。只有一条视图，和视图起点那个可以抬起来的基准。

## 30 秒启动

需要 Python 3.11+、PySide6、Markdown。密钥放在 User 环境变量 `DEEPSEEK_API_KEY` 里。

```powershell
cd D:\LMY\coding\aichat\a
.\run.ps1
```

`run.ps1` 会自动从 User 环境变量取出密钥、找到本机解释器并启动。用别的解释器：

```powershell
$env:DELTA_PYTHON = "C:\path\to\python.exe"
.\run.ps1
```

或者：

```powershell
pip install -r requirements.txt

```

默认数据目录是 `%APPDATA%\Delta`；加 `--data D:\somewhere` 可换。

## 怎么用

- **视图**只有一条：根 → 从基准沿默认走到的叶子。基准以上走**结构**，基准以下走**默认**；没有另存的"当前位置"。
- **层**是 parent 底下那排孩子，标签条是它的入口：
  - **点标签** = 切换（只改这一层的一个默认）；
  - **+** = 新建（parent 是提问 → 新答案；parent 是回答 → 新问题）；
  - **×** = 关闭（有后续就删整棵子树，报数确认）；
  - **拖动** = 重排展示顺序（不改出生序、不改默认、不改视图）。
- 单孩子层这一轮沿用卡片的**右键菜单**作为入口（"在这一层新建 / 关闭这一支 / 抬基准"）；连体标签形态留到下一轮。
- **锁**：某一层在捷径链（根 → 基准）上时，切换、新建、关闭、重排全部不可用。点一下只会进入确认态；确认 = **把基准抬到这一层的 parent**，四类操作一起恢复。不设单键快捷键。
- **ATLAS** 点节点 = **设基准**；锁集是派生出来的，从不单独写。每次基准变化都会给一条文字提示。
- 顶栏菜单：**回到默认路线**（基准 = 根）和 **把捷径写进默认…**（只写链上各层的默认，不解锁、不改基准）。
- **发送**在视图末端追加。如果视图正好停在一条提问上（回答还没生成），发送会说明原因，用这一层的 **+** 生成回答。
- **Enter** 发送，**Shift+Enter** 换行，**Esc** 停止（已收到的半个回答保留）；**Ctrl+N** 新对话，**Ctrl+L** 对话库，**Ctrl+M** 收起/展开 ATLAS。

## 它特别在哪

不是把树画成一张需要拖拽的画布，也不是在聊天气泡旁边塞一棵缩进树。

**模型只有三样状态**：结构（孩子 + 出生序 + 每层展示序）、每层至多一个活动孩子、基准。视图、捷径链、锁层、路线段全是**派生**的。没有路径副本，没有"当前节点"字段。

**锁的对象是层，不是控件。** 标签条、右键菜单、快捷键都只是入口；所有会改层的入口最终只经过核心的四个方法，每个方法先 `require_open(layer)`。唯一的全局例外是"把捷径写进默认"，它需要显式确认，并且只写链上各层的默认。

**切换只换后缀**：视图的前缀控件原样保留，切回来复用同一张卡片；流式只改一个卡片；重启只恢复基准和滚动锚点。

## 数据与性能

- **结构**：节点 + parent；出生序 append-only；每层展示序是独立排列。
- **默认**：字段挂在 parent 上，语义是"这一层的活动孩子"，至多一个，可空。
- **基准**：一个节点；空对话为 `None`。
- **视图**：`祖先链(descend(基准))` — 纯函数。
- **持久化**：每次操作原子写 JSON（schema 2）；旧文件（schema 1）在内存里迁移：把旧可见链一次性写进默认、基准 = 根，首屏不变、无锁、回默认不跳。
- **流式**：后台 daemon 线程只把 delta 放进队列；主线程 14ms 批量取一次。流式期先追加纯文本草稿，完成时一次性做完整 markdown 排版。

## 已知边界

- 这一轮只改模型与行为：配色、图标、动效没有重画；删掉了旧的卡片按钮和首选圆点，标签条改为单行滚动并加了 ×/+。单孩子层的连体标签形态、锁的视觉、横向滚动条的外观留到下一轮；因此单孩子层暂时用右键菜单作为入口。
- 截图来自上一轮；视觉下一轮统一更新。旧的"两行分支条 / 首选圆点"截图和脚本已删除，因为它们描述的行为已经不存在。
- Markdown 是 Qt 富文本的子集；流式期间是纯文本草稿，完成时才排版。
- ATLAS 为小树设计；几百个节点会变密，尚无搜索/缩放。
- 密钥从环境变量读取；删除单条消息没有撤销（整份对话删除会进 trash）。
- 单人、单机、单 provider（OpenAI 兼容；默认 DeepSeek）。

## 一句话

**最值得说的是：视图不是被存下来的，而是被算出来的——结构、每层至多一个活动孩子、一个基准。锁不是开关，而是基准派生出来的一组层；四个入口只是层的手，层才是对象。**
